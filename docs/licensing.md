## Rules for contributors

- Do not copy, paste or translate code from GPL sources (Cumination or others).
- Describe provider behaviour in your own words in the PR (URLs/endpoints used, fields
  parsed), and implement from that description and your own fixtures.
- Third-party media in tests: only synthetic data or openly licensed media (see below).
  Never commit adult media, thumbnails or HTML captures containing adult imagery.
